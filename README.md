# 一人公司临时团队指挥官

帮一个人老板把任务清楚、合规、有人性地交给真人与 AI 临时团队，并按标准完成交付、验收、付款和结项。

## v1.1 交付闭环版升级说明

这一版从“临时团队建议器”升级为“一人公司临时团队交付闭环”：

- 增加任务分诊表：自己做、AI 做、自由职业者做、服务商做、顾问做、线下协助做，或直接砍掉。
- 增加 AI 临时员工分工：资料员、文案初稿员、质检员、表格整理员、任务秘书、代码助理、客服脚本员。
- 增加真人角色画像库：PPT/视觉、剪辑内容、资料整理、开发自动化、专业服务商、顾问专家、北京线下协助、平台劳动者。
- 增加完整交付闭环：定义目标、拆包、招募、试工、启动、里程碑、验收、返工、付款、归档、复盘。
- 增加北京本地执行检查：地址、通行、等待、交通、餐补、现场联系人、安全、应急、隐私和学校/家庭/客户设备边界。
- 增强人文关怀条款：不要求 24 小时在线，不用免费试工拿成果，不用模糊反馈压人，新增需求先确认费用和时间，平台劳动者的等待、路程、材料和安全要被尊重。

## 它解决什么问题

一人公司不一定永远一个人干。真实情况往往是：平时一个人，遇到项目、客户、活动、交付高峰，就需要临时组织一支小队。

这支小队可能包括：

- AI 临时员工
- 自由职业者
- 专业服务商/工作室
- 兼职或线下临时协作者
- 顾问型专家
- 你自己这个最终负责人

这个 Skill 的目标不是教你“便宜用人”，而是帮你把任务拆清楚，把边界说清楚，把验收标准写清楚，同时保护承接方的尊严、时间和专业自主权。

核心原则：

> 给任务，不支配人。  
> 管交付，不控制过程。  
> 讲边界，不临时加码。  
> 要效率，也要尊重。

## 适合谁

- 一人公司 / OPC
- 独立开发者
- 自由职业者
- 小工作室主理人
- 需要临时外包、短期协作、AI 员工编排的人
- 在北京/中国内地场景下，需要考虑交付、合规、版权、隐私和协作伦理的人

## 标准协作边界

```text
本任务采用成果交付方式。委托方只定义目标、交付物、截止时间、验收标准和合规边界；承接方可自主决定工作方法、工具、时间安排和内部协作方式。除约定交付节点外，不要求随时在线或接受额外未约定任务。
```

## 示例

输入：

```text
我下周五要给客户交一个 20 页提案 PPT，一个人做不完，预算 3000 元，能不能帮我组织一个临时团队？
```

输出会包含：

- 哪些内容由你自己决定
- 哪些内容让 AI 先做
- 是否需要 PPT 设计师、行业顾问或资料整理员
- 每个角色的任务书
- 招募文案
- 试工题
- 验收标准
- 付款和改需求规则
- 版权、保密和人文关怀检查
- 结项归档和下次合作记录

## 不是法律意见

这个 Skill 面向实际协作决策，不替代律师、会计师、人力资源专业人士或政府部门意见。涉及长期固定用工、劳务派遣、个人信息、未成年人数据、医疗教育数据、税务发票、合同纠纷等情况时，应进一步咨询专业人士。
